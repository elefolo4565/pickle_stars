# ピックルスターズ (Pickle Stars)

ブラウザで遊べる、オンライン対戦のピックルボールゲームです。
2.5 頭身くらいのトゥーン調キャラクターで、PC とスマホのどちらでも遊べます。

- **オンライン対戦**: クイックマッチ / ルームコード（招待リンク）で 1 対 1
- **CPU と練習**: 3 段階の強さ。ブラウザ内だけで動くのでサーバー不要
- **6 キャラクター**: ピコ / モモ / ガンテツ / ルナ / ボルト / ココ（見た目だけの違い）
- **ピックルボールのルール**: 対角サーブ、ツーバウンドルール、キッチン（ノンボレーゾーン）、
  ラリーポイント / サイドアウト、11 点先取・2 点差（5/7/11/15 点を選べる）
- 60fps を目標にした軽量な描画（three.js、gzip 後 約 155KB）

## 技術構成

| 部分 | 技術 |
|---|---|
| クライアント | three.js + Vite（素の JavaScript） |
| サーバー | Node.js + ws（WebSocket） |
| 共有ロジック | `shared/`（ルール・物理・CPU AI。サーバーとブラウザで同じコードを使う） |

### ネットワーク同期の仕組み

- サーバーが権威を持ち、60Hz で試合を進めて 30Hz でスナップショットを送る
- ボールは決定的な物理計算なので、クライアントはサーバーの状態から**現在時刻まで先読み**して表示する
- 自分の移動はクライアント側で即時反映（サーバーは移動速度の上限で検証）
- 自分の打球もローカルで即座に反映し、サーバーは**最大 300ms さかのぼるラグ補償**で判定する
- 失点の確定には 300ms の猶予があり、遅れて届いた正当な打球で取り消せる

## 開発

```bash
npm install
npm test          # ルール・CPU 対戦のテスト
npm run build     # dist/ にクライアントを出力
npm start         # http://localhost:3000 でサーバー起動（dist/ も配信）
```

クライアントを編集しながら確認する場合は、`npm start` と並行して `npm run dev`
（http://localhost:5173 、/ws はサーバーへ中継）を使います。

### オンライン対戦を 1 人で確認する

```bash
# ブラウザで「ルームを作る」→ 表示されたコードを指定
node tools/bot-client.js ABCD
# 片道 80ms の遅延を入れて試す
LAG=80 node tools/bot-client.js ABCD
```

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左をドラッグ |
| 強打 | J / スペース | 赤ボタン |
| ソフト（ドロップ・ディンク） | K | 青ボタン |
| ロブ | L | 黄ボタン |
| エモート | 1〜8 | 右上の顔ボタン |

ゲームパッドにも対応しています（左スティック / A=強打 B=ソフト X・Y=ロブ）。
